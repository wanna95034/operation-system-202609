# operation-system-2026

《操作系统分析与设计实习》题目五：基于 FAT 的模拟磁盘文件系统。

项目计划采用 C++17 实现文件系统核心，并使用图形界面展示目录、FAT、磁盘块和已打开文件表状态。

## 核心约束

- 128 个物理块，每块 64 字节；
- FAT 占用第 0、1 块；
- 根目录固定在第 2 块；
- 使用 8 字节定长目录项；
- 支持多级目录、绝对路径和最多 5 个打开文件；
- 所有磁盘访问通过块 I/O 和双缓冲完成。
