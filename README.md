## 核心约束

- 128 个物理块，每块 64 字节；
- FAT 占用第 0、1 块；
- 根目录固定在第 2 块；
- 使用 8 字节定长目录项；
- 支持多级目录、绝对路径和最多 5 个打开文件；
- 所有磁盘访问通过块 I/O 和双缓冲完成。
